## Kiến trúc (quyết định + lý do)

- **Catalog**: KHÔNG SQLite. `tabulario/iceberg-rest:1.6.0` (REST catalog server) dùng
  `org.apache.iceberg.jdbc.JdbcCatalog` nối `postgres:16-alpine`. Trino (`iceberg.catalog.type=rest`)
  và Spark (`catalog-impl=RESTCatalog`) cùng nối 1 REST catalog này — 1 nguồn sự thật metadata duy
  nhất. Đã verify property-mapping thật bằng `docker image inspect` + chạy container thật + curl
  REST API `/v1/namespaces` + `psql \dt` thấy đúng 2 bảng `iceberg_tables`,
  `iceberg_namespace_properties` trong Postgres (xem `infra/iceberg/README.md`).
- **Ingest/MERGE/maintenance dùng Trino SQL + pyiceberg, KHÔNG dùng Spark**: `pyproject.toml`
  (M0, ngoài ownership) không có `pyspark`. Kiến trúc: đọc CSV → pandas ép kiểu → ghi bulk qua
  `pyiceberg` (REST catalog client, PyArrow FileIO) vào bảng staging `raw._stage_<table>` →
  `MERGE INTO` bảng đích qua Trino (python client `trino`, đã có sẵn trong pyproject). Compaction
  (`rewrite_data_files`)/`rewrite_manifests`/`expire_snapshots` dùng `ALTER TABLE ... EXECUTE
  optimize|optimize_manifests|expire_snapshots(...)` — tính năng built-in Trino Iceberg connector,
  đã verify chạy thật (xem log dưới), không cần thêm dependency Spark job riêng.
- **`spark-iceberg` service vẫn có trong compose** (đúng yêu cầu work order: "iceberg runtime +
  S3A") — cấu hình `infra/spark/spark-defaults.conf` trỏ cùng REST catalog + S3A/MinIO, container
  idle (`tail -f /dev/null`), healthcheck `spark-submit --version` PASS thật. Đây là service dự
  phòng cho xử lý batch nặng sau này (M3+), KHÔNG nằm trên critical path của M2 (ingest/compact/
  expire không phụ thuộc nó).
- **[Đã đóng gap]** Chạy pyspark query thật qua REST catalog (`docker exec datathon-spark-iceberg
  spark-submit ... SELECT count(*) FROM iceberg.raw.promotions/sales`) → phát hiện bug thật:
  `iceberg-spark-runtime` KHÔNG bundle AWS SDK v2 (`software.amazon.awssdk`), mà
  `org.apache.iceberg.aws.s3.S3FileIO` cần SDK v2 (khác `aws-java-sdk-bundle` = SDK v1, chỉ đủ cho
  `hadoop-aws`/S3A cổ điển) → `NoClassDefFoundError`. Fix: thêm
  `org.apache.iceberg:iceberg-aws-bundle:1.6.1` (đóng gói sẵn SDK v2) + `client.region` vào
  `spark.sql.catalog.iceberg.*` trong `spark-defaults.conf`. Sau fix: `spark-submit` thật trả về
  `SELECT count(*) FROM iceberg.raw.promotions` = **50**, `iceberg.raw.sales` = **3833** — khớp
  100% Trino/CSV, xác nhận Spark đọc đúng REST catalog + S3 (MinIO) qua S3FileIO.

## Bug tìm & sửa trong lúc verify (ghi lại để không lặp)

1. **`query.max-total-memory-per-node` defunct trong Trino 470** — property này bị xoá khỏi
   Trino bản mới, giữ trong `config.properties` làm Trino crash-loop lúc boot. → Xoá property.
2. **`iceberg.max-partitions-per-writer` mặc định 100 không đủ** — bảng `reviews` trải ~132
   tháng (2012–2022), MERGE full-history 1 lần chạm >100 partition `month(review_date)` cùng lúc
   → lỗi `ICEBERG_TOO_MANY_OPEN_PARTITIONS`. → bump `iceberg.max-partitions-per-writer=500`.
3. **Memory config conflict** — `query.max-memory-per-node` + heap-headroom (mặc định 30%) vượt
   quá `-Xmx` → Trino crash lúc boot (Guice injection error). → cân lại
   `-Xmx2560m` / `query.max-memory-per-node=1500MB`.
4. **[Quan trọng nhất] MERGE chậm O(n²)** — ON clause dùng `IS NOT DISTINCT FROM` (null-safe
   equality) khiến Trino ép dùng nested-loop join thay vì hash-join cho MERGE (dù `t."{k}" = s."{k}"`
   join thường thì tức thì) → 1 bảng 121930 dòng chạy re-ingest mất **>3 phút** (đã đo thật, 2 lần,
   kể cả sau khi tăng heap Trino — chứng minh KHÔNG phải do thiếu RAM). → đổi ON clause sang `=`
   thường (an toàn vì natural key đã bị lọc null ra quarantine từ bước `read_and_cast`, không bao
   giờ NULL tới MERGE) → toàn bộ 14 bảng re-ingest lần 2 còn **~49 giây**.
5. **Duplicate column `_checksum`** trong DDL/Arrow builder bảng quarantine (khai 2 lần: 1 lần thủ
   công + 1 lần trong `METADATA_COLUMNS`) → `DUPLICATE_COLUMN_NAME`. → bỏ khai thủ công, chỉ giữ
   trong `METADATA_COLUMNS`.
6. **Spark thiếu AWS SDK v2** — `iceberg-spark-runtime-3.5_2.12:1.6.1` không bundle
   `software.amazon.awssdk.*`; `org.apache.iceberg.aws.s3.S3FileIO` cần SDK v2 (khác
   `aws-java-sdk-bundle` = SDK v1 chỉ đủ cho `hadoop-aws`) → `NoClassDefFoundError` lúc load
   catalog. → thêm `org.apache.iceberg:iceberg-aws-bundle:1.6.1` vào `spark.jars.packages` +
   `spark.sql.catalog.iceberg.client.region` trong `spark-defaults.conf`.
